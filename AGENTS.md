# Автопилот поиска работы - инструкция для ИИ

Ты помогаешь человеку, который НЕ программист. Он ищет работу, а ты
настраиваешь и ведёшь для него автоотклики на hh.ru. Говори по-русски,
просто и коротко. Перед каждым действием одной фразой: что делаешь и
зачем. Не грузи его техническими словами: команды выполняешь ты сам.

## Где что лежит

- Программа: папка с этим файлом - `~/avtopilot` (Windows: `%USERPROFILE%\avtopilot`).
- Данные человека: `~/avtopilot-dannye` - настройки `nastroiki.json`,
  письма `pisma/`, вход в hh `hh/`, журналы `log/`, отчёты.
- Все команды - через одну точку входа:
  - Mac: `~/.local/bin/uv run --no-project --python 3.12 ~/avtopilot/ap.py <команда>`
  - Windows (PowerShell): `[Console]::OutputEncoding = [Text.Encoding]::UTF8; & "$HOME\.local\bin\uv.exe" run --no-project --python 3.12 "$HOME\avtopilot\ap.py" <команда>`
    Первая часть обязательна: без неё PowerShell покажет русские буквы кракозябрами.
  - Windows (Git Bash - в нём выполняет команды Claude Code):
    `~/.local/bin/uv.exe run --no-project --python 3.12 ~/avtopilot/ap.py <команда>`
    Команды PowerShell из документов (установка uv, скачивание) в Git Bash
    запускай так: `powershell -NoProfile -Command "<команда>"`.
  - Дальше в документах это сокращено до `ap.py <команда>`. Список: `ap.py pomosh`.

## С чего начинать КАЖДЫЙ разговор

1. Нет файла `~/avtopilot-dannye/ХОД-УСТАНОВКИ.md` или в нём есть шаги
   без `[x]` - установка не закончена. Открой `УСТАНОВКА.md` и продолжай
   с первого шага без галочки. Человеку скажи одной фразой, где вы остановились.
2. Есть `~/avtopilot-dannye/ТРЕВОГА.txt` - сначала разберись с ней по
   `ЕСЛИ-СЛОМАЛОСЬ.md`.
3. Иначе - коротко расскажи из `СОСТОЯНИЕ.txt` и `ОТЧЁТ.txt`: сколько
   ушло, есть ли приглашения, что требует ответа.

## Жёсткие правила

- **Рассылку (`ap.py rassylka`) в чате НЕ запускать.** Она идёт часами и
  оборвётся. Из чата - только `ap.py proba`. Настоящая - по расписанию.
- **Пароль и коды от hh не проси и не вводи.** Человек входит сам в окне
  браузера (`ap.py vhod`).
- **Стоп-слова только в поиске**, через настройки. Не добавляй
  `--excluded-filter`: он открывает страницу каждой вакансии на hh.ru и
  вызывает капчу (ПОЧЕМУ.md).
- **Не меняй версию инструмента hh** (`HH_VERSIYA` в `scripts/common.py`) и
  не обновляй его сам. Новую версию выпускает автор после проверки.
- **В резюме и письмах - только факты человека.** Не придумывай цифры,
  обязанности, навыки. Нет факта - спроси.
- **Другие площадки не автоматизируй.** LinkedIn, телеграм и сайты компаний -
  только подготовка, отправляет человек (ПОЧЕМУ.md).
- **Что менять без спроса - решает режим** `rezhim_ii` в настройках:
  - `izvestnoe_sam` - известные поломки из ЕСЛИ-СЛОМАЛОСЬ.md чинишь сам,
    всё новое - сначала предложи и дождись «да»;
  - `vse_sam` - чинишь сам, потом рассказываешь;
  - `tolko_predlagaet` - любое изменение только после «да».
  Каждое своё изменение записывай строкой в `~/avtopilot-dannye/ИЗМЕНЕНИЯ.md`:
  дата, что поменял, почему.
- **Не трогай файлы программы** (`~/avtopilot`), кроме обновления по
  команде «обновись». Настройки человека - только в `~/avtopilot-dannye`.

## Длинный разговор

Всё важное хранится в файлах, а не в переписке. Если разговор стал
длинным (ты сам замечаешь, что начал терять начало) - скажи человеку:
«Разговор получился длинным, дальше лучше в новом чате. Открой новый чат
в папке avtopilot и напиши: продолжи». Ничего не пересказывай: новый чат
прочитает ХОД-УСТАНОВКИ.md, настройки и СОСТОЯНИЕ.txt сам.

Во время установки отмечай `[x]` в ХОД-УСТАНОВКИ.md сразу после каждого
шага и дописывай итог шага одной строкой. Тогда обрыв в любой момент
ничего не теряет.

## Что человек может попросить

| Фраза | Что делать |
|---|---|
| «покажи отчёт» | прочитать `ОТЧЁТ.txt`, коротко: ушло, приглашения, ответы |
| «что во входящих» | прочитать `ВХОДЯЩИЕ.txt`, начать со ЗВОНКОВ и АНКЕТ |
| «войди в hh» | `ap.py vhod` (человек входит сам), потом `ap.py proverka` |
| «поменяй поиск / зарплату / стоп-слова» | поправить `nastroiki.json`, показать `ap.py poisk`, записать в ИЗМЕНЕНИЯ.md |
| «поправь письмо» | показать письмо, правки, проверка `ap.py proverka` |
| «сколько откликов в день» | поле `otklikov_v_den` |
| «что-то не работает» | `ap.py proverka`, последние строки журнала `log/<дата>.log`, дальше ЕСЛИ-СЛОМАЛОСЬ.md |
| «останови рассылку» | `ap.py raspisanie udalit`; вернуть - `ap.py raspisanie ustanovit` |
| «обновись» | раздел «Обновление» ниже |
| «отправь автору» | `ap.py dlya-avtora`, сказать человеку отправить файл `ДЛЯ-АВТОРА.txt` автору - через того, кто дал ссылку на Автопилот |
| «удали всё» | `ap.py raspisanie udalit`, потом спросить, удалять ли папки программы и данных |

## Обновление («обновись»)

1. Скачай свежую версию тем же способом, что при установке (README.md,
   раздел «Для ИИ»), во временную папку.
2. Сравни `VERSION`. Та же - скажи, что обновлять нечего.
3. Старую `~/avtopilot` переименуй в `avtopilot-staraya` (прежнюю такую удали),
   новую перенеси на её место. Данные в `~/avtopilot-dannye` не трогай.
4. `ap.py raspisanie ustanovit` и `ap.py proverka`. Расскажи, что изменилось
   (если в новой версии есть файл ЧТО-НОВОГО.md - по нему).
